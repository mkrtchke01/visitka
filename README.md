# Как менять сайт

Вся информация находится в файле `index.html`. Откройте его в любом редакторе текста, внесите изменения и сохраните файл.

## Что можно менять

- **Город, телефон, имя, цены и тексты:** нажмите `Ctrl + F`, введите старый текст и замените его.
- **Показ блоков и текста:** пролистайте `index.html` в самый низ и найдите комментарий `ЧТО ПОКАЗЫВАТЬ НА САЙТЕ`. Найдите строку с нужным названием, например "Вакцинация": true, и замените только `true` на `false`. Не пишите `false` рядом с текстом на странице и не меняйте название в кавычках.

```js
"Срочный выезд на дом": true,
"Текст на главном экране": true,
"Вакцинация": true,
"Telegram": true
```

## Ссылки на мессенджеры

Ссылки находятся прямо в двух меню «Связаться в мессенджере». Над каждой группой ссылок есть комментарий с примерами. Меняйте адрес после `href=` в строке нужного мессенджера.

Примеры: Telegram — `https://t.me/ваш_ник`; WhatsApp — `https://wa.me/79991234567` (номер без `+` и пробелов). Для MAX и VK вставьте полную ссылку на страницу врача.

Если какой-то мессенджер не нужен, найдите его название в списке «ЧТО ПОКАЗЫВАТЬ НА САЙТЕ» и поставьте `false`.

## Как добавить услугу

В разделе «Услуги» есть комментарий `НОВАЯ УСЛУГА`. Он подсказывает, как скопировать карточку, поменять текст и добавить новый пункт в список включения/выключения.

## Фото

Главное фото находится в папке `assets` и называется `veterinarian-hero.png`. Чтобы заменить его, загрузите новое фото в эту папку с таким же именем.
