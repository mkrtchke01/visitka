# Как менять сайт

Вся информация находится в файле `index.html`. Откройте его в GitHub, нажмите значок карандаша, внесите изменения и нажмите **Commit changes**. Сайт обновится сам через несколько минут.

## Что можно менять

- **Город, телефон, имя, цены и тексты:** нажмите `Ctrl + F`, введите старый текст и замените его.
- **Мессенджеры:** найдите `anna_vet_example` и замените на ник врача. Для WhatsApp найдите `79990000000` и введите номер без `+`, например `79991234567`. Ненужный мессенджер можно удалить целой строкой с его названием.
- **Срочный выезд и услуги:** внизу `index.html` есть понятный список. Поставьте `false`, чтобы скрыть блок, или `true`, чтобы снова показать его.

```js
"Срочный выезд на дом": true,
"Вакцинация": true,
"Анализы и диагностика": true,
"Домашний визит": true
```

## Как добавить услугу

В разделе «Услуги» есть комментарий `НОВАЯ УСЛУГА`. Скопируйте карточку услуги над этим комментарием, вставьте копию перед ним и поменяйте название, описание и цену. Если будет сложно — пришлите текст новой услуги, и мы добавим её.

## Фото

Главное фото находится в папке `assets` и называется `veterinarian-hero.png`. Чтобы заменить его, загрузите новое фото в эту папку с таким же именем.
