# Как менять сайт

Вся информация находится в файле `index.html`. Откройте его в любом редакторе текста, внесите изменения и сохраните файл.

## Что можно менять

- **Город, телефон, имя, цены и тексты:** нажмите `Ctrl + F`, введите старый текст и замените его.
- **Мессенджеры:** найдите `anna_vet_example` и замените на ник врача. Для WhatsApp найдите `79990000000` и введите номер без `+`, например `79991234567`. Ненужный мессенджер можно удалить целой строкой с его названием.
- **Показ блоков и текста:** внизу `index.html` найдите комментарий `ЧТО ПОКАЗЫВАТЬ НА САЙТЕ`. У каждого пункта есть `true` или `false`. Поставьте `false`, чтобы скрыть элемент, или `true`, чтобы снова показать его. Не меняйте название в кавычках.

```js
"Срочный выезд на дом": true,
"Текст на главном экране": true,
"Вакцинация": true,
"Telegram": true
```

## Как добавить услугу

В разделе «Услуги» есть комментарий `НОВАЯ УСЛУГА`. Он подсказывает, как скопировать карточку, поменять текст и добавить новый пункт в список включения/выключения.

## Фото

Главное фото находится в папке `assets` и называется `veterinarian-hero.png`. Чтобы заменить его, загрузите новое фото в эту папку с таким же именем.
