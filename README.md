# Сайт-визитка ветеринара

Статичный одностраничный сайт: без JavaScript, фреймворков и сборки. Для публикации достаточно загрузить репозиторий в Vercel — платформа автоматически отдаст `index.html`.

## Где менять информацию

Весь текст находится в [index.html](index.html): имя врача, телефон, e-mail, адрес, часы работы, описания услуг и цены. Для быстрой замены используйте поиск по текущим значениям, например `+7 999 000-00-00` или `Анна Мельникова`.

Главное фото — [assets/veterinarian-hero.png](assets/veterinarian-hero.png). Оно сгенерировано ИИ для этого проекта и не взято из фотостоков. Чтобы поставить своё фото, замените этот файл, сохранив имя, либо укажите другой путь в `src` у изображения в `index.html`.

Внешний вид и адаптивность находятся в [styles.css](styles.css). Основные цвета собраны в начале файла в блоке `:root`.

## Проверка локально

Откройте `index.html` двойным щелчком в браузере. Ссылки телефона и e-mail уже работают на мобильных устройствах и в поддерживающих приложениях.

## Деплой на Vercel

1. Зайдите в [Vercel](https://vercel.com/new) и импортируйте репозиторий `mkrtchke01/visitka`.
2. Оставьте настройки без изменений: это обычный статичный сайт без команды сборки.
3. Нажмите **Deploy**. После каждого push в `main` Vercel будет публиковать новую версию автоматически.
